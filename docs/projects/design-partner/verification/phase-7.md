walk exposed append-instead-of-replace input and incomplete native key metadata;
real Save/correction/Enter now guard these paths. CLI file validation also had
to cover transitive local assets and remain valid until the operation completed:
a real concurrent MCP write reproduced a changed-byte capture before the queue
fix. The final independent concurrent add/write proof preserves checked bytes.
Lessons 83–84 record those reusable failures.

failure is negative evidence, whereas missing provenance or synthetic output
is unavailable. Candidate false-ready defects gate rollout; baseline defects
remain descriptive. Producing-agent browser usage is recorded, not required for
comparison eligibility. Final assessment is independent of the producer.

No product operation, CLI verb, shared-core calculation, README capability or
workflow default changes in this preparation. Existing CLI/API operations perform
the canvas work in both conditions. The study has an explicit repository CLI,
help, documentation and tests; real browser walks verify interaction. The generic
browser helper adds only an optional owned-proxy argument. The API boundary guard
recognizes the exact frozen stock fixture endpoint while continuing to reject
