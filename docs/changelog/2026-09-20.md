# 20 September 2026

## A forwarded roadmap keeps its undo gesture

The home forward now carries the request's existing `group` field. Previously,
a 111-card roadmap imported directly took one undo, but the same import through
a replica took 111: `forwardSubmit()` dropped the field while rebuilding the
request. The 19 September journey used direct mode and missed that route.

A new two-daemon regression derives the same synthetic reading over both HTTP
paths, checks the group on every request received by the authoritative writer
and every recorded entry, then checks one undo removes all 111 cards. It waits
for the replica's final sequence before reading its state. The test-only commit
reproduces the forwarded 111 → 110 failure while its direct control stays green.

`scripts/journey-roadmap-forward.mjs` separately drives the real CLI against a
pinned public source, then presses Ctrl+Z in a real browser. The forwarded case
has no `ISOCAN_DIRECT`; both homes and all listener ports are private to the run.
The request types, operation vocabulary and roadmap parser are unchanged.
