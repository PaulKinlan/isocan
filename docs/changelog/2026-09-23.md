# 23 September 2026 — The shelf's manifest learns to say how it is called

The wasm tool shelf's manifest pinned everything about its modules except the
one thing a caller needs: the calling convention. `hash.wasm`'s digest, bytes
and description were all declared — and how to pass it input and read its
output existed only in the drive transcript of the lane that had measured it.
The gap was found from the outside: voicebox's provider read this shelf to call
`hash`, and had to measure the ABI itself (input at a fixed `0x400`, the export
called with the input length, the 32-byte digest at `0x2400`, `-1` over 8192 —
known-answer-tested against `sha256('abc')`). A shelf whose contract lives in a
drive transcript is a shelf nothing else can safely call.

So the manifest declares the ABI now, as data. `ModuleManifest` gains `tools`:
each tool names its module file under `assets/`, the 64-hex sha256 an admission
pinned, and an `abi` block — `family` (the convention's name; the driven family
is `buffer-abi/1`), `input` `{addr, maxBytes}`, `output` `{addr, bytes}`,
`call` `{export}`. Shape problems refuse the add and the load (`toolProblems`,
beside `assetProblems` and wired into the same two paths), with synthetic
manifests driving every refusal in `packages/core/test`.

Two rules keep the field honest, and both are in the design note. **Only what
was measured is written down:** `hash`'s declaration is measured and
known-answer-tested, and the installed shelf's manifest carries it as of today;
`diff`'s output format is measured-but-undecoded, so it declares no `abi` — a
caller refuses an undeclared ABI by name rather than probing one. **The
manifest declares; the caller's driven set decides:** shape validation checks
that the ABI is exactly declared, never that the family is understood —
understanding is the caller's admission, per the scene's own rule that a digest
proves byte integrity, not safety.

Both consumers verified against the declaring manifest before landing: isocan's
loader reads `@isocan/wasm-tools` as `loaded`, and voicebox's provider suite
still passes nine of nine (it ignores the field until its measured table learns
to prefer the manifest's own words).
